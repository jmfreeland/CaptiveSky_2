# Listening Stones: witnessed quiet-listening practice

When an autonomous resident lingers quietly at the Listening Stones, a distinct
resident can retain a private place-practice memory if they are within 9 m,
facing the listener, and have clear Visibility-channel line of sight. The memory
attributes the listener when their agent identity is known, records the
Listening Stones and current island day, and is tagged as direct visual evidence.
The listener is not treated as their own witness; players and nearby residents
without memory components are excluded. Similar practice memories are suppressed
for 12 real-world hours. Ordinary chime memories remain based on audibility and
are unchanged.

No model calls, global lore, or world-state mutation are involved. The new
resident-memory automation assertions cover eligibility, exclusions, attribution,
and duplicate suppression. The UE 5.8.3 isolated editor target compiled and
linked successfully on 2026-10-29. A NullRHI automation launch reached platform
validation but produced no project/test log, so runtime assertions and a live
Island check remain pending.
