# Weather-driven DynamicWind for instanced Megaplants (2026-10-18)

The four locally installed Fab PVE species already have enabled UE 5.8 `UDynamicWindSkeletalData` profiles and their instanced-skinned hosts select `UDynamicWindData` when no custom transform provider is supplied. Until now, Island weather drove the older Fab foliage-material wind collection but did not publish parameters to UE's `DynamicWind` world subsystem, so those Megaplants could have a valid provider and still lack Island weather motion.

`UIslandEnvironmentSubsystem` now creates a transient, tileable 64x64 linear RGBA noise texture at world begin play (two independently seeded fractal channels, sampled at mip 0 by the DynamicWind shader). Every 0.2 seconds it passes the current `AIslandWeather::SampleWind` direction and cm/s speed, full profile amplitude, and noise texture to `UpdateWindParameters`. Weather updates are bounded to 5 Hz; the existing Fab material-wind path is unchanged and remains the fallback if the transient texture or plugin API is unavailable. No Content asset or saved map was changed.

The installed plugin's public `DynamicWindSubsystem.h` currently includes `DynamicWindLog.h`, but that header is absent from the installed plugin tree. The subsystem's `UpdateWindParameters` is marked `UFUNCTION(BlueprintCallable)`, so the bridge discovers its class and function through Unreal reflection and validates the reflected struct type before invoking it. This avoids depending on the broken header; `IslandEnvironment` automation now checks the reflected class, subsystem, function contract, generated texture settings/variation, and wind-parameter mapping.
