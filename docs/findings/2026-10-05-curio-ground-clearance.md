The resident-scale ground-cover capture shows the cairn almost swallowed by tall grass; only its upper stones are readily visible. See [Codex_CairnResidentScale.png](../../Saved/CompileScratch/Codex_UnderstoryVerify_20261002/Project/Saved/Viewpoints/2026-10-05_193158_h12.0/Codex_CairnResidentScale.png). The source change reserves compact clearings around the persisted curio records during ground-cover placement: 210 cm around cairns, 170 cm around seed pods, and 65 cm around small trail stones. The weather actor defers scatter initialization by one tick so the world-state subsystem can load saved record locations first. Only ordinary ground-cover plants are excluded; tree groves and the wider meadow layout are otherwise unchanged. Boundary checks were added to `CaptiveSky2.Agent.GroundCover`.

The 5.8.3 editor target built successfully before the visual integration fix (full build at 19:13 UTC; incremental weather rebuild at 19:27 UTC), and `CaptiveSky2.Agent.GroundCover` passed. An initial 12:00 capture then logged zero curios when scatter initialized even though the capture harness loaded eight saved curios later; that image was not evidence that the clearances worked.

The capture harness now preloads read-only curio preview actors before ground-cover scatter and reuses them when it adds the rest of the saved-world previews, preventing duplicates. The changed test translation unit compiled with the project's VS 14.44 response file and the module linked to a temporary DLL. `CaptiveSky2.Visual.Viewpoints` passed using that DLL; the harness reported eight preloaded curios and produced [06_CairnResidentScale.png](../../Saved/Viewpoints/2026-10-05_210305_h12.0/06_CairnResidentScale.png). The cairn is readable inside the open patch. The original project DLL was restored byte-for-byte after the test.
