# Morning dew glints: isolated validation (2026-10-08)

The new dew subsystem derives a short-lived glint strength from low morning
sun, wetness, rain, cloud cover, and storm intensity. Its transient actor
maintains at most 360 tiny non-colliding instances in an 11 m disc around the
player. The local material asset is generated by
[`Create-IslandDewMaterial.py`](../../Scripts/Create-IslandDewMaterial.py);
the code stays hidden if that optional asset is absent.

## Validation

- The UE 5.8.3 `CaptiveSky_2Editor` scratch target returned success and was
  already up to date (zero build actions).
- `CaptiveSky2.Agent.IslandDew` passed in that isolated scratch editor with
  `-NullRHI`, Python and agent thinking disabled, model requests capped at
  zero, and a 60-second realtime cap. It covers weather gates, clamping,
  instance-count bounds, distance sizing, and resident description text.
- A separate scratch-editor Python audit recompiled the existing material in
  memory and reported `instanced=True`, additive blend, unlit shading, and no
  compile errors. It did not save the shared `.uasset`.
- Log: [`Codex_IslandDew_Validation_20261008.log`](../../Saved/CompileScratch/Codex_RavenCrabAttention_20261008/Saved/Logs/Codex_IslandDew_Validation_20261008.log).
- Material audit: [`Codex_IslandDewMaterialAudit_20261008.log`](../../Saved/CompileScratch/Codex_RavenCrabAttention_20261008/Saved/Logs/Codex_IslandDewMaterialAudit_20261008.log).

These checks still do not prove the glints are legible, grounded, attractive,
or inexpensive in a rendered frame. No PIE visual check was performed. The
material asset currently exists locally, but it is ignored by Git; regenerate
it with the script if it is absent on another checkout. Next, take a matched
dawn capture and measure the frame-time effect before calling the visual or
performance result successful.
