## Raven art options (checked 2026-10-01)

The local Content inventory contains only `M_RavenPlaceholder` and `BP_Raven_Placeholder`; there is no reusable bird mesh in the project. Two external directions are known, but neither has been imported:

- [Common raven scan, Virtual Museums of Małopolska](https://sketchfab.com/3d-models/common-raven-ec9c0ac738fd4495af334ea2092e8d89): CC0, 384.3k triangles. It is a strong form reference and reusable source mesh, but that triangle count is unsuitable as-is for this real-time character; decimation, LODs, and a rig/animation would still need to be evaluated.
- [Low Poly Bird: Raven, Fab](https://www.fab.com/listings/2b9f53d9-dc77-4911-be89-4e5a5147344b): the listing describes a stylized rigged raven with 12 animations and an Unreal Engine package. Its page presents a license selector and purchase controls; exact current price/terms require selecting the license in Fab.

No download or Content edit should happen until the user picks a direction. If cost remains off the table, the scan route is possible but entails more art/rig work and should first be tested on a duplicate prototype, leaving the current Blueprint recoverable.
