# Procedural Vegetation Editor availability (2026-10-10)

UE 5.8.3 includes the Experimental `ProceduralVegetationEditor` plugin at `Engine/Plugins/Experimental/ProceduralVegetationEditor`. Its descriptor is marked `IsExperimentalVersion: true` and `EnabledByDefault: false`. `CaptiveSky_2.uproject` now enables it for the next project launch.

To check compatibility first, I enabled the plugin in the ignored isolated scratch descriptor at `Saved/CompileScratch/RatAnimationProbe_20261010/CaptiveSky_2.uproject`. The installed engine mounted `ProceduralVegetationEditor` and loaded both `UnrealEditor-ProceduralVegetation.dll` and `UnrealEditor-ProceduralVegetationEditor.dll`. UBT accepted the PVE-enabled project configuration, and the scratch editor completed the existing `CaptiveSky2.Agent.RatLocomotionAnimation` test under `NullRHI`, disabled resident thinking, zero model requests, and a 60-second cap ([log](../../Saved/CompileScratch/RatAnimationProbe_20261010/PVEAvailability.log)). After that compatibility check, I added the same plugin enablement to the main `.uproject`. The currently open editor was not restarted, so PVE will only be active there after the next restart; no Content or live session state was changed.

This proves the installed 5.8.3 PVE plugin can load in a scratch copy of this project; it does not prove interactive vegetation authoring, generated asset quality, Nanite suitability, compatibility with the existing Fab Megaplants, or runtime performance. The next useful experiment, once the project is restarted, is to author one small, distinct woodland-edge species/variation in PVE, then validate its export/materials and compare a bounded HISM placement against the existing vegetation before considering any broad scatter.

The first PVE probe lacked the project-local `Plugins/PlantFactoryPlugin` directory and therefore reported its material-function references missing. I corrected the scratch setup with a junction to the main project's content-only plugin (no assets copied or modified) and reran startup. `PVEPlantSupportProbe.log` now confirms both `ProceduralVegetationEditor` and `PlantFactoryPlugin` mount, the PVE editor module loads, the plant packages scan without `LoadErrors`, and `CaptiveSky2.Agent.RatLocomotionAnimation` passes. This validates plugin discovery and package-mount compatibility in the isolated scratch project; it does not validate interactive PVE authoring or rendered/runtime behavior in the live project.
