## What was wrong, and what changed

- **Lifetime thinking cap.** `AutonomousAgentAIController` stopped a resident thinking after 30 autonomous
  requests, and budget refusals counted towards the cap, so continuous play went quiet after about half an
  hour. Codex fixed this in `688ca27`.
- **Residents never moved on.** The prompt never explained `wander`, but said repeatedly that idle is a
  valid choice. The cairn (19 m from Aster's start, noticed at 15 m) and the first trail stone (20 m,
  noticed at 8 m) were just out of perception. `adc1498` adds one sentence about wander, and a note after
  six unprompted decisions within about 12 m. Wander went from 0 to 16 in comparable time.
- **Weather described as rendering.** About 700 characters per turn of rain-streak fields,
  collision-sampled splashes and listener-dependent ambience went to every resident. `b0b999b` describes
  only what a resident would feel.
- **Inn counter goal on the roof.** `move_to InnCounter` projected the marker with a 10 m vertical extent
  and landed on the roof navmesh (Z 3424 vs floor 2690). Routes out of the inn were complete. The new
  `Island.NavProbe X Y Z` console command (`a500c0e`) shows this against the navmesh the game actually
  loads. `ProjectGroundedTarget` now searches floor-level navigation first, samples nearby floor rings before an elevated fallback, and the saved-Island blockout audit checks that `InnCounter` resolves near floor height with a complete path from ListeningStones. The original failure still merits a bounded PIE check of actual movement completion.
- **Raven weaving without twigs.** The raven tried to weave twice with an empty beak and then gave up.
  `f50254a` tells it that twigs are only on open ground.
- **Crash.** An access violation on a render worker thread after 9 minutes, with only engine code on the
  stack. `cc8db32` makes `Start-Spectator.ps1 -Continuous` relaunch after a crash (at most five times an
  hour).

## Still open

- **Wander had no memory of where it had been.** In `Wander2`, residents' walks drifted east, while the
  trail, cairn and pod are all west and south-west, so nothing new came into view. Wander now ranks up
  to eight complete, reachable candidates against the resident's last eight successful wander
  destinations. This should reduce repeats, but it does not aim at known curios; a fresh time-capped
  continuous run should check whether roaming broadens naturally before adding any
  landmark bias.
- **Budget pacing.** At 90 requests an hour, three residents who each want a turn about once a minute are
  refused about a third of the time. Codex's `688ca27` changed how refusals are handled; worth rechecking.
- **The raven's `sleep` at a roost** was refused as "not a supported inn bed" (Codex's `b760f0f` addressed
  perch sleep; not yet seen in a run).

do not treat the sweep as runtime-validated until a bounded PIE run confirms movement from the selected
start. A retry using an isolated project copy and the cached UBT XML configuration remained silent for

UBT's single-instance mutex is keyed to the installed
`UnrealBuildTool.dll` path rather than the project path, so an isolated project copy still contends for
it. Do not bypass this with `-NoMutex`. Inspection of the installed UE 5.8 source confirms that a
`-WaitMutex` invocation can be silent while waiting: in
`Engine/Source/Programs/UnrealBuildTool/UnrealBuildTool.cs`, build mode calls
`SingleInstanceMutex.Acquire` on the global UBT mutex before platform registration or build execution;
with `-WaitMutex`, this happens before build progress is reported. This alone does not identify the
observed stall point: `SingleInstanceMutex.AcquireNowOrThrow` uses `TryAcquire` when `-WaitMutex` is
absent, so a global-mutex conflict should return instead of waiting.

### Quiet-turn model tier and Island chronicle (2026-09-29)

The next local milestone routes only uneventful turns to the configured light model. Being addressed, another resident
within six metres, a build option, or an interactable within four metres keeps the full model; light responses are
restricted to idle, move_to, wander, and sleep. This saves the full prompt and first-person image for decisions where
they matter, while continuous sessions keep separate light-request accounting and explicit run caps.

The new `WorldState/chronicle.jsonl` is a spectator-facing event record, not another resident memory: it records
decisions/speech, lasting world changes, weather and Island-day transitions without making an LLM call. The companion
`Scripts/Build-Chronicle.py` groups events by day and folds quiet movement into short summaries; it can produce
Markdown or standalone HTML. It never feeds its contents back into residents. The standalone HTML now renders those
quiet summaries as blockquotes; a synthetic test caught and corrected a marker-detection bug.

UE 5.8.3 compiled the local model-tier/chronicle modules, and all 28 non-live agent automation tests passed in
`Saved/Logs/Codex_MergedAgentSuite_2026-09-29.log`. The live provider test was excluded; the script's two Python
render/escaping tests pass with the UE-bundled Python 3.11. Next, a deliberate, tightly capped live run should check
that the light tier actually handles quiet turns and that the chronicle stays readable without changing its role as
an observer-only record.
