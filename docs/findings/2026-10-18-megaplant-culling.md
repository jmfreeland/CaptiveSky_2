# UE 5.8 per-instance controls for skinned foliage

`AIslandInstancedSkinnedFoliage` now exposes the UE 5.8 `UInstancedSkinnedMeshComponent` fade-start, fade-end, and per-instance animation screen-size settings. The host applies them through the component's public setter APIs whenever it rebuilds its instances. This gives future PVE Megaplant placements a way to fade out and stop animating tiny far-canopy copies without changing the mesh, transform-provider, or wind setup.

Defaults remain zero, so existing actors keep the engine's default behavior: no per-instance fade, and the global animation screen-size threshold is inherited. Negative distance values are clamped to zero; a non-finite animation threshold falls back to zero. The component APIs and their meanings are documented in the installed UE 5.8 header at `Engine/Source/Runtime/Engine/Classes/Components/InstancedSkinnedMeshComponent.h`.

The focused automation fixture checks that the fade distances and animation threshold reach the component and that negative distances/NaN do not leak through. A UE 5.8.3 `CaptiveSky_2Editor` build succeeded from a source snapshot under `Saved/CompileScratch/Codex_MegaplantCull_20261018` (six incremental compile/link actions); the scratch target has separate `Binaries` and `Intermediate`, so the main editor's loaded DLL was not relinked. The first compile caught that the component's reflected fields are protected; the implementation now uses its public `SetCullDistances` and `SetAnimationMinScreenSize` APIs. The focused NullRHI automation was then attempted once but crashed during `StartOfEnginePreInit`, before test discovery, with an access violation and the known project-open stack hash `F405610C114D120D4B6F5ABA901EC469AC9FAA26` ([crash context](../../Saved/CompileScratch/Codex_MegaplantCull_20261018/Saved/Crashes/_0000/CrashContext.runtime-xml)). Therefore the fixture has compiled but has not passed at runtime. The live editor has not been used for visual validation because its main window timed out on activation and the available capture did not show Unreal. No map or Content asset was changed, and no Megaplant has been tuned or enabled with these controls yet.

Next gate: after a working editor session is available, use the previewed Aspen/Hazel assets to compare default animation and draw behavior against a conservative far-canopy threshold at the same camera views, then verify fade/LOD readability and runtime frame-time impact before authoring any values onto the Island.
