# Raven roost choice in heavy rain (2026-10-03)

The raven already receives two separate kinds of local roost evidence: measured wind shelter and five short visibility probes above the perch marker. The overhead probes are only a small rain-cover clue; they do not prove that a site is dry, strong, or safe. Before this change, opportunistic `BeginPerch()` considered wind and travel distance, but ignored those already-measured overhead clues.

The selector now samples current rain intensity and each physically supported roost's overhead probe count. Only during a strong shower (rain intensity at least 0.55) can a site with at least two more overhead hits than the wind-aware choice change the preference. Among sites with nearly the best cover count, the existing wind-and-distance selector still decides. Missing or mismatched cover samples, no meaningful cover difference, and lighter rain all preserve the existing wind-aware/nearest behavior. The five short vertical probes first test collision-visible geometry, then test any remaining samples against conservative upper-crown envelopes for mature spruce HISM instances. This reuses rendered trees without enabling foliage collision or affecting navigation. The crown envelope is only a local cover clue, not proof of dryness, density, or safety. This acts only after the raven has already chosen an action that may perch; it does not force him to seek shelter or add model requests.

The situation summary and system prompt describe the evidence as a clue rather than a guarantee. The `RavenPerch` automation's saved-Island section checks support and flight routes in the editor world; it does not call `InitializeGroundCover()`. Its 0/5 canopy-aware reading therefore only describes the editor-world geometry at test time and must not be treated as evidence about the generated runtime forest. The separate `GroundCover` fixture verifies crown detection with synthetic mature/sapling instances. The `Visual.Viewpoints` test initializes the actual Island scatter when run with `-GroundCover`; use that transient preview world for any real-map canopy measurement, and clear preview foliage after inspection.

Deterministic assertions cover heavy-rain preference, light-rain fallback, insufficient cover difference, wind choice between similarly covered sites, malformed evidence, and synthetic upper-crown segment geometry (including a tilted tree). The `CaptiveSky2.Agent.GroundCover` fixture also adds known mature and sapling instances: a mature non-colliding HISM tree covers the expected probe, a short sapling does not, and collision remains disabled. The four changed translation units compiled with the installed UE 5.8.3 MSVC toolchain using generated compiler response files; the isolated scratch module linked successfully. Separate `UnrealEditor-Cmd` runs passed both `CaptiveSky2.Agent.RavenPerch` and `CaptiveSky2.Agent.GroundCover` (one test each). This focused scratch-module validation is not a full UBT project build or a live gameplay session. The main UE editor remained open and untouched.
