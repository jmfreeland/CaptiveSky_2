# Night sky visibility probe (2026-10-03)

The earlier Day 1, 00:00 Tideglass capture was a new-moon state and its camera faced away from the Moon, so it did not prove that the lunar disk was missing. A dedicated Day 15, 00:00 UE 5.8.3 D3D12 SceneCapture pointed toward the zenith and confirmed the full-moon disk renders through the cloud layer. The `CaptiveSky2.Visual.Viewpoints` test passed for that probe. The capture is [here](../../Saved/CompileScratch/Codex_UnderstoryVerify_20261002/Project/Saved/Viewpoints/2026-10-03_141827_h00.0/06_MoonZenithProbe.png); the log is [here](../../Saved/Logs/Codex_MoonZenithProbe_Day15_20261003.log). The temporary probe camera was added only to the disposable scratch project's `Config/IslandViewpoints.json` and then removed; the main map and user-edited viewpoint config were not changed.

The level's `IslandDayNight.Moon` uses `bAtmosphereSunLight=true`, light index 1, and an atmosphere disk color scale of white. Its missing appearance in the Tideglass frame was a framing issue, not a broken moon-light configuration.

Stars are still absent from the visible night sky. UE's built-in `/Engine/MapTemplates/Sky/M_Procedural_Sky_Night` has its `Stars` static switch enabled and references `T_Sky_Stars`, but its parent `M_Procedural_Sky_MASTER02` is an opaque, lit surface material that renders a complete sky. Applying it as a dome would cover/replace the project's existing SkyAtmosphere and dynamic cloud look; it is not a safe drop-in star overlay. Keep the current atmosphere and cloud treatment, and prototype a distinct, depth-tested star layer or a project-owned overlay material before changing the level. Do not modify shared `Content/` assets while Claude's material work is active without coordinating first.

The 30 FPS minimum remains enforced for gameplay-scale foliage captures. A separate Tideglass capture reported 18.34 FPS while the main editor was also open; that concurrent run is not a clean performance baseline. Re-run the gameplay-scale check only when the main editor is idle, and do not infer packaged or target-hardware performance from SceneCapture throughput.
