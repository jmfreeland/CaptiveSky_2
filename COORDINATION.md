# Agent Coordination

This repo is worked on by more than one AI coding assistant (Claude Code, Codex CLI,
possibly others) against the same working tree, often in separate terminals at the
same time. This file is the shared handoff point so two agents don't edit the same
files at once or silently clobber each other's uncommitted work.

Both `AGENTS.md` (read by Codex CLI) and `CLAUDE.md` (read by Claude Code) point here.
**Read this file before starting work, and update it before you start editing.**

## Protocol

1. Before touching files, run `git status` / `git diff` to see what's already
   uncommitted. If another agent's WIP is sitting there, don't overwrite it —
   either build on it, ask the user, or wait.
2. Add a row to the **Active Work** table below naming the files/areas you're about
   to change and what you're doing. Keep it to one line.
3. Commit in small, coherent steps (this repo's git log is full of small single-purpose
   commits — match that style). A committed change is much easier for the other agent
   to work around than a pile of uncommitted edits.
4. When you finish, remove your row from **Active Work**. No need to log completed
   work here — `git log` is the record of what shipped.
5. If you need to touch files another agent has claimed, say so to the user rather
   than editing around them silently.
